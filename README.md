# PromptSSD

![PromptSSD Logo](public/logo-dark.svg)

A community-driven web application for sharing, discovering, and referencing AI prompts. Think Reddit for prompt engineering.

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **State Management:** [Zustand](https://zustand-demo.pmnd.rs/) (planned)
- **UI Components:** [Shadcn/ui](https://ui.shadcn.com/) (planned)
- **Animation:** [Framer Motion](https://www.framer.com/motion/) (planned)
- **Authentication:** [Auth.js](https://authjs.dev/) (planned)
- **Database:** [PostgreSQL](https://www.postgresql.org/) with [Drizzle ORM](https://orm.drizzle.team/) (planned)
- **Deployment:** [Vercel](https://vercel.com/)

## 📋 Features (Planned)

- 🔍 Discover and search AI prompts across different categories
- 💬 Share your own prompts with the community
- ⭐ Upvote and save your favorite prompts
- 🏷️ Tag and categorize prompts for easy discovery
- 👥 User profiles and reputation system
- 💾 Reference and version prompts
- 🔐 Secure authentication and authorization

## 🏃‍♂️ Getting Started

### Prerequisites

- Node.js 20+
- npm or pnpm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/shrvansudhakara/prompt-ssd.git
cd prompt-ssd
```

2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🧰 Available Scripts

- `npm run dev` - Start development server with Turbopack
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint
- `npm run format` - Format code with Prettier
- `npm run format:check` - Check code formatting
